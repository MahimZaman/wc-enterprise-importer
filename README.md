# WooCommerce Enterprise Importer

Enterprise-grade WooCommerce bulk product importer.

## Installation and use

Place the `wc-enterprise-importer` directory in `wp-content/plugins/` and activate **WooCommerce Enterprise Importer** from the WordPress Plugins screen.

Requires WooCommerce. Several import, validation, and retry classes are empty in this development snapshot.
